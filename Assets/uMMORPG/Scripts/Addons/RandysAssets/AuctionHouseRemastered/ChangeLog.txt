1.0
	Initial Release for uMMORPG Remastered 2.30 (Addon built from addon version 1.4.3c for uMMORPG 3D/2D)
		- Added Multiple Auction Houses based off an Id on the player. This will enable you to have seperate auction houses based on class or if your
		  game has factions. All players with the same Id will see the same auctions.
		
		- Closeing the Auction House UI now clears the ui and defaults back to the browse tab.

		- The auction durations on the auctions tab when creating auctions will now auto populate the number of days into the toggle buttons text.
