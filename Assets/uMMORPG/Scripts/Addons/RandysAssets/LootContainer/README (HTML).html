Randy's Loot Container Addon for uMMORPG

 

With this addon you can create items that reward selected items, gold, and/or coins. You can set the min and max amount of the item/gold/coin along with the chance to receive each.

To create a new loot container:

  1. Navigate to Assets/uMMORPG/Resources/Items inside unity.
  2. If you wish you can create a folder in there called any name of your choice.
  3. Select the folder where you wish to create the item and right click it then navigate to 'Create/uMMORPG Item/Randy's Assets/' and click on 'Loot Container'.
  4. Fill out all the info for your new loot container.
ToolTip Info:
    {REWARDS} : To display the rewards, stack size, and their probabilty chance.
   
Note: Do not set stack sizes higher than an items max stack size or items will be lost if player does not have enough inventory space. If your container needs to contain more than the stack size of an item, create multiple of the same item inside the loot container.
